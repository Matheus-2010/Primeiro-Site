Primeiro Site 
Meu primeiro projeto de desenvolvimento web, criado durante meus estudos de programação.

Sobre o projeto
Este projeto foi desenvolvido para praticar os fundamentos do desenvolvimento front-end, utilizando HTML para estruturar a página e CSS para definir sua aparência.

Tecnologias utilizadas

HTML5
CSS3

Objetivo
Colocar em prática os conhecimentos adquiridos durante meus estudos, desenvolver minhas habilidades em criação de páginas web e acompanhar minha evolução como desenvolvedor.

Acesso ao projeto
Demonstração on-line: será adicionada após a publicação pelo GitHub Pages.
Repositório: https://github.com/Matheus-2010/Primeiro-Site

Aprendizados
Estrutura básica de uma página HTML.
Organização de elementos na página.

Estilização com CSS.
Prática de desenvolvimento front-end.
